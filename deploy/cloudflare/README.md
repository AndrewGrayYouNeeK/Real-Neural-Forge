# Cloudflare Containers front door

This directory is a Worker named `real-neural-forge-api`. It is not the
dashboard Worker `real-neural-forge` or `youneek-xyz`.

Deploy steps, the Workers Paid plan, and the required secrets are in the
repository README under **Live hosting**. Run Wrangler from this directory
after `npm install`. Do not move `wrangler.jsonc` to the repository root.
