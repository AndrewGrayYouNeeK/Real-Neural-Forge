API docs and examples

Nous is a small time-series model you can train on your own numbers, plus live weather, markets, and space answers in the chat. The examples below use the public site origin. Replace the host if you are calling a local server. Text answers are free. Training needs a free account and stays under published caps. GQ voice is included with the Nous Plus subscription.

The machine-readable schema stays at /openapi.json, with a generated explorer at /openapi/docs and /openapi/redoc.

Health

curl -sS https://nous.youneek.dev/health

A healthy process returns {"status":"ok"}.

Sample models (no account)

New accounts also get private copies of these starters: Central Park temperature, AAPL daily return, Bitcoin daily return, near-Earth approaches, and moon illumination. The public catalog and forecasts need no sign-in. 

curl -sS https://nous.youneek.dev/starters

curl -sS "https://nous.youneek.dev/starters/weather/forecast?points=16"

Other starter ids are stocks, crypto, near-earth, and lunar. Each forecast includes recent history and a next-step prediction. These are shipped samples, not live forecasts.

Predict and forecast

POST /predict scores a sequence against the loaded champion model. The default response is a single point: {"prediction":[...]}. 

curl -sS -X POST https://nous.youneek.dev/predict \
  -H "Content-Type: application/json" \
  -d '{"sequence":[[0.1],[0.2],[0.3],[0.4]]}'

POST /forecast asks for a multi-step outlook from the same model. See the schema for horizon and quantile fields. 

curl -sS -X POST https://nous.youneek.dev/forecast \
  -H "Content-Type: application/json" \
  -d '{"sequence":[[0.1],[0.2],[0.3],[0.4]],"horizon":3}'

Workspace training (signed in)

Caps are public so you can see the limits before you upload. Authenticated routes accept a session cookie from the site, or Authorization: Bearer YOUR_TOKEN. 

curl -sS https://nous.youneek.dev/workspace/limits

# After you upload a CSV (multipart) and get a dataset id:
curl -sS -X POST https://nous.youneek.dev/workspace/datasets/DATASET_ID/train \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_column":"value"}'

curl -sS -X POST https://nous.youneek.dev/workspace/models/MODEL_ID/predict-latest \
  -H "Authorization: Bearer YOUR_TOKEN"

Live data

These routes are answered by the Worker in front of the API. They do not require an account. 

curl -sS "https://nous.youneek.dev/live/weather?q=Dallas"

curl -sS "https://nous.youneek.dev/live/quote?kind=stock&q=AAPL"

curl -sS -X POST https://nous.youneek.dev/agent/chat \
  -H "Content-Type: application/json" \
  -d '{"question":"What can Nous do?"}'

# Optional history and mode. The agent may call forecast, live-data, and
# evaluation tools before answering.
curl -sS -X POST https://nous.youneek.dev/agent/chat \
  -H "Content-Type: application/json" \
  -d '{"question":"How accurate is the weather sample?","mode":"normal","history":[]}'

# Unhinged mode on the agent route (same voice rules as /live/ask).
curl -sS -X POST https://nous.youneek.dev/agent/chat \
  -H "Content-Type: application/json" \
  -d '{"question":"What can Nous do?","mode":"unhinged"}'

# Phase 4: read an image or chart (PNG/JPEG/WebP/GIF data URL, max 1.5 MB).
# Returns a description, any chart numbers as a series, and a quick forecast.
curl -sS -X POST https://nous.youneek.dev/agent/vision \
  -H "Content-Type: application/json" \
  -d "{\"question\":\"Where is this heading?\",\"image\":\"data:image/png;base64,$(base64 -w0 chart.png)\"}"

# Phase 5: world model simulator. Baseline vs scenarios, 14 days, weather in °F.
curl -sS -X POST https://nous.youneek.dev/analysis/simulate \
  -H "Content-Type: application/json" \
  -d '{"starter_id":"weather","display_unit":"°F","horizon":14,"scenarios":[{"name":"Cold snap","events":[{"kind":"shock","step":1,"value":-15}]}]}'

# Self-supervised world model: backtest PCA vs JEPA encoders, simulate with the winner.
curl -sS -X POST https://nous.youneek.dev/analysis/simulate \
  -H "Content-Type: application/json" \
  -d '{"starter_id":"lunar","horizon":14,"encoder":"auto"}'

# Fallback without tools (unchanged):
curl -sS -X POST https://nous.youneek.dev/live/ask \
  -H "Content-Type: application/json" \
  -d '{"question":"What can Nous do?"}'

curl -sS -X POST https://nous.youneek.dev/live/ask \
  -H "Content-Type: application/json" \
  -d '{"question":"What can Nous do?","mode":"unhinged"}'

POST /agent/chat is the tool-calling chat agent. Same request shape as /live/ask (question, optional mode, optional facts) plus optional history. It may call tools such as forecast, fetch_live_data, get_evaluation_metrics, compare_horizons, explain_prediction, and list_user_series, then returns only the final answer text plus tools_used. Cap every model call with the same neuron budget as /live/ask.

mode is optional. normal answers directly and briefly, with light wit secondary to the answer. Casual profanity is fine when it fits. unhinged cusses a lot, jokes, and trash-talks the chat, the data, and bad forecasts, then still gives the real answer and the confidence. Both still refuse hate, slurs, harassment, threats, sexual content involving minors, and illegal instructions. Anyone can use either mode. Optional facts asks the model to rewrite that text in the selected voice while keeping every number, unit, and confidence figure exactly. Omit it for a normal question. /live/ask stays available as a non-agent fallback.

General answers use GPT-OSS 120B. A successful reply adds voice_resting and voice_message. After the free daily neuron budget, voice_resting is true for everyone except the owner and voice_message is “Voice is resting for today, text still works.” Text still arrives. GET /live/budget reports the same flag without spending a reply. Past the hard daily safety cap the reply is “Daily limit reached, back tomorrow.” The owner skips the per-visitor cap and still counts toward that global cap.

Sign-in

Chat and tool endpoints need a signed-in account. Sign up or log in with POST /auth/signup or POST /auth/login ({"email": "…", "password": "…"}). The session is an HttpOnly, Secure, SameSite=Strict cookie that lasts 14 days. Send it on later calls (for example curl -c jar -b jar). Without it the API answers 401 {"auth_required": true}. Public without sign-in: /, /docs, /openapi.json, /health, and shared report links. Daily AI caps are counted per account. Five wrong passwords in 15 minutes lock that email for 15 minutes.

Related container routes include GET /lunar, GET /space/near-earth, and GET /space/solar-system.
