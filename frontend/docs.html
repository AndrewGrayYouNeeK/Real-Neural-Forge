API docs and examples

Neural Forge is a small time-series model you can train on your own numbers, plus live weather, markets, and space answers in the chat. The examples below use the public site origin. Replace the host if you are calling a local server. Text answers are free. Training needs a free account and stays under published caps. GQ voice uses credits. Payments are not live — checkout is in test mode and will not charge a real card.

The machine-readable schema stays at /openapi.json, with a generated explorer at /openapi/docs and /openapi/redoc.

Health

curl -sS https://forge.youneek.dev/health

A healthy process returns {"status":"ok"}.

Sample models (no account)

New accounts also get private copies of these starters: Central Park temperature, AAPL daily return, Bitcoin daily return, near-Earth approaches, and moon illumination. The public catalog and forecasts need no sign-in. 

curl -sS https://forge.youneek.dev/starters

curl -sS "https://forge.youneek.dev/starters/weather/forecast?points=16"

Other starter ids are stocks, crypto, near-earth, and lunar. Each forecast includes recent history and a next-step prediction. These are shipped samples, not live forecasts.

Predict and forecast

POST /predict scores a sequence against the loaded champion model. The default response is a single point: {"prediction":[...]}. 

curl -sS -X POST https://forge.youneek.dev/predict \
  -H "Content-Type: application/json" \
  -d '{"sequence":[[0.1],[0.2],[0.3],[0.4]]}'

POST /forecast asks for a multi-step outlook from the same model. See the schema for horizon and quantile fields. 

curl -sS -X POST https://forge.youneek.dev/forecast \
  -H "Content-Type: application/json" \
  -d '{"sequence":[[0.1],[0.2],[0.3],[0.4]],"horizon":3}'

Workspace training (signed in)

Caps are public so you can see the limits before you upload. Authenticated routes accept a session cookie from the site, or Authorization: Bearer YOUR_TOKEN. 

curl -sS https://forge.youneek.dev/workspace/limits

# After you upload a CSV (multipart) and get a dataset id:
curl -sS -X POST https://forge.youneek.dev/workspace/datasets/DATASET_ID/train \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_column":"value"}'

curl -sS -X POST https://forge.youneek.dev/workspace/models/MODEL_ID/predict-latest \
  -H "Authorization: Bearer YOUR_TOKEN"

Live data

These routes are answered by the Worker in front of the API. They do not require an account. 

curl -sS "https://forge.youneek.dev/live/weather?q=Dallas"

curl -sS "https://forge.youneek.dev/live/quote?kind=stock&q=AAPL"

curl -sS -X POST https://forge.youneek.dev/live/ask \
  -H "Content-Type: application/json" \
  -d '{"question":"What can Neural Forge do?"}'

# Optional. Omit mode, or pass "normal", for the default voice.
curl -sS -X POST https://forge.youneek.dev/live/ask \
  -H "Content-Type: application/json" \
  -d '{"question":"What can Neural Forge do?","mode":"unhinged"}'

mode is optional. normal allows casual profanity when it fits. unhinged cusses a lot, jokes, and trash-talks the chat, the data, and bad forecasts, then still gives the real answer and the confidence. Both still refuse hate, slurs, harassment, threats, sexual content involving minors, and illegal instructions. Anyone can use either mode.

Related container routes include GET /lunar, GET /space/near-earth, and GET /space/solar-system.
